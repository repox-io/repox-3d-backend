# Repox 3D API

Backend service powering the Repox 3D Utilities.

## Tech Stack

- **Language:** Java
- **Framework:** Spring Boot
- **Database:** PostgreSQL

## API Documentation

Once running, interactive documentation is available at:

- **Swagger UI:** `http://localhost:8080/swagger-ui.html`
- **OpenAPI Spec:** `http://localhost:8080/v3/api-docs`

## Related Projects

- [Repox 3D Viewer](https://3d.repox.io) — client-side visualisation UI
- [Repox Store](https://repox.io/en)
